Welcome to the **Bethlehem Built** (formerly "The Modern Disciple") Church Tech Site repository. This project is a responsive, single-page website for Bethlehem Built — an IT consulting service dedicated to equipping churches and small businesses for the modern world.

## How to Publish This Site for Free

You can easily publish this `index.html` file on the web for free using either GitHub Pages or Netlify.

### Option 1: GitHub Pages (Recommended if you host code here)
1. Ensure your repository is public.
2. Go to your repository **Settings** on GitHub.
3. In the left sidebar, click on **Pages**.
4. Under "Source", select the **main** branch (or master) and the **root** folder (`/`), then click **Save**.
5. After a few minutes, your site will be live at `https://[your-github-username].github.io/[repository-name]/`.

### Option 2: Netlify (Fast & Easy Drag-and-Drop)
1. Go to [Netlify Drop](https://app.netlify.com/drop).
2. Drag and drop the folder containing your `index.html` file into the upload area.
3. Netlify will instantly publish your site and provide a live link.
4. You can create a free account to customize the domain name (e.g., `bethlehem-built.netlify.app`) or link a custom domain.
